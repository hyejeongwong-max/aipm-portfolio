# aipm-portfolio · AI产品经理个人主页

年轻 AI 科技感的单页个人主页 / 作品集，适配电脑与手机双端，内置「点哪改哪」的页面内编辑能力。

- 在线预览：https://hyejeongwong-max.github.io/aipm-portfolio/
- 当前版本：V0.1.0

## 特性

- **双端响应式**：桌面宽屏与手机窄屏自适应，导航在移动端折叠为汉堡菜单。
- **页面内编辑**：点右上角「编辑」进入编辑模式，点文字直接改；新增 / 删除技能组、项目、经历、联系方式；改动自动保存在本机浏览器（localStorage），刷新不丢。
- **配置导入导出**：编辑工具条可导出 `portfolio-config.json` 备份，换设备 / 换浏览器时导入恢复；可一键恢复默认占位内容。
- **单文件零依赖**：原生 HTML / CSS / JS，无构建、无框架，浏览器直开即可。

## 本地预览

直接用浏览器打开 `index.html`，无需安装任何环境。

## 如何修改内容

1. 打开页面，点右上角「编辑」进入编辑模式。
2. 直接点击要改的文字（姓名、头衔、简介、技能、项目、经历、联系方式）进行修改，自动保存。
3. 用底部工具条的「+ 添加」新增条目，条目右上角「删除」移除。
4. 改完点「完成编辑」锁定；建议点「导出配置」留存备份。

> 说明：编辑内容只保存在当前浏览器本机，不会同步到服务器；换设备或清缓存前请先导出配置并导入。
